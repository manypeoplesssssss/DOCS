---

# 2. 중요한 라벨링 원칙

이미지에 보이는 결함은 모두 라벨링해야 한다.

예를 들어 이미지에:

```text
scratch
white_paint
```

가 모두 존재하는데 `scratch`만 Bounding Box를 만들면 `white_paint`가 배경으로 취급될 수 있다.

따라서 부분적으로만 라벨링된 이미지를 학습 데이터로 사용하는 것은 주의해야 한다.

---

# 3. 초기 데이터 문제

초기 CVAT Export:

```text
전체 이미지: 532
라벨된 이미지: 86
Bounding Box: 183

white_paint: 60
scratch: 123
```

나머지 이미지가 정상 이미지라고 확인된 것이 아니었다.

단순히 아직 라벨링하지 않은 이미지였다.

따라서 이를 Negative Sample로 학습시키지 않았다.

# 12. 핵심 원칙

```text
미라벨링 이미지 ≠ 정상 이미지
```

정상 이미지라고 확실히 확인되지 않은 이미지를 무조건 Background Sample로 학습시키지 않는다.

Annotation 품질은 모델 성능에 직접 영향을 준다.
