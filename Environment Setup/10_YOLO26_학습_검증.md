# 2. v2 학습

사용 모델:

```text
yolo26n.pt
```

명령:

```bash
yolo detect train \
  model=yolo26n.pt \
  data=/home/gi/yolo26-defect/dataset_v2/dataset/data.yaml \
  epochs=100 \
  imgsz=640 \
  batch=8 \
  device=0 \
  project=/home/gi/yolo26-defect/runs \
  name=defect_v2
```

# 3. 주요 옵션



```text

```

```text

```
