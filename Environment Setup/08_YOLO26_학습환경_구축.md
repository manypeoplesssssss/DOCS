# YOLO26 학습 환경 구축

## 1. Workspace 생성

WSL Ubuntu:

```bash
cd /home/gi
```

```bash
mkdir -p yolo26-defect
```

```bash
cd yolo26-defect
```

최종 Workspace:

```text
/home/gi/yolo26-defect
```

---

# 2. Python 가상환경

생성:

```bash
python3 -m venv .venv
```

활성화:

```bash
source .venv/bin/activate
```

활성화되면 Terminal 앞에:

```text
(.venv)
```

가 표시된다.

---

# 3. pip 업데이트

```bash
python -m pip install --upgrade pip
```

---

# 4. Ultralytics 설치

```bash
pip install -U ultralytics
```

구축 당시 사용된 Ultralytics:

```text
8.4.171
```

---

# 5. 설치 확인

```bash
yolo version
```

또는:

```bash
python -c "import ultralytics; print(ultralytics.__version__)"
```

---

# 6. GPU 확인

```bash
python -c "import torch; print(torch.cuda.is_available())"
```

정상:

```text
True
```

GPU:

```bash
python -c "import torch; print(torch.cuda.get_device_name(0))"
```
