# CVAT + YOLO26 Troubleshooting

## 1. Nuclio Function unhealthy

확인:

```bash
nuctl get functions
```

문제:

```text
ultralytics-yolo26
unhealthy
1/1
```

Container:

```bash
docker ps -a --filter "name=ultralytics-yolo26"
```

로그:

```bash
docker logs nuclio-nuclio-ultralytics-yolo26
```

---

# 2. best.pt FileNotFoundError

실제 오류:

```text
FileNotFoundError:
[Errno 2] No such file or directory: 'best.pt'
```

문제 코드:

```python
model = YOLO("best.pt")
```

수정:

```python
model = YOLO("/opt/nuclio/best.pt")
```

---

# 3. Docker COPY best.pt 실패

시도했던 설정:

```yaml
directives:
  postCopy:
    - kind: COPY
      value: best.pt /opt/nuclio/best.pt
```

오류:

```text
COPY best.pt /opt/nuclio/best.pt

"/best.pt": not found
```

Nuclio Build Log에서는:

```text
COPY handler /opt/nuclio
```

가 이미 수행된다.

따라서 `best.pt`를 Function Directory 안에 두고 별도 COPY 지시를 제거하였다.

최종:

```text
serverless/ultralytics/yolo26/nuclio/best.pt
```

Python:

```python
YOLO("/opt/nuclio/best.pt")
```

절대 경로 사용.

# 7. 모델이 white_paint를 탐지하지 않음

초기 테스트에서 이미지에는 white paint가 보였지만 Detection이 나오지 않았다.

Ground Truth 확인:

```bash
cat <label-file>.txt
```

해당 이미지의 Label에는 `scratch`만 존재했다.

즉 모델 Threshold만의 문제가 아니라 Training Annotation 자체에서 `white_paint`가 누락된 사례였다.

해결:

```text
Annotation 추가
→ Dataset v2 생성
→ YOLO26 재학습
```

# 14. Nuclio 재배포 후 확인

배포 성공 메시지만 보고 끝내지 않는다.

반드시:

```bash
nuctl get functions
```

확인.

정상:

```text
ready
1/1
```

배포 메시지가 성공이어도 Function 초기화 단계에서 오류가 발생하면 `unhealthy`가 될 수 있다.

# 15. 데이터 삭제 주의

다음 명령:

```bash
docker compose down -v
```

은 Volume을 삭제할 수 있다.

CVAT 데이터를 유지해야 한다면 함부로 사용하지 않는다.

# 16. 가장 중요한 문제 해결 순서

```text
문제 발생
   ↓
상태 확인
   ↓
로그 확인
   ↓
정확한 Error 확인
   ↓
해당 부분만 수정
   ↓
재배포
   ↓
ready 1/1 확인
   ↓
CVAT에서 실제 실행
```

추측해서 여러 설정을 동시에 변경하기보다 로그를 먼저 확인한다.
